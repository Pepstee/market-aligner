a skill catalogue. Return ONE JSON object matching the skill_normalise schema and

Guidance:
  - Prefer an EXISTING canonical id from the known list provided in the input.
  - If none fits but the term clearly names a real tool, propose a new lowercase

    return canonical_id "" with low confidence.
  - confidence 0-1: how sure the mapping is. Be conservative — low confidence
    keeps the merge unapproved until a human confirms it.
