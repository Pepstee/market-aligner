Rules:
  - job_title, company: copy raw, keep the original language.
  - mapped_career: single best fit from the list above, else "other".
  - entry_level: true if the posting reads 신입 (entry) / 경력무관 (experience
    irrelevant) / 인턴 (intern); false if 경력 (experienced required); null if
    genuinely unclear. Judge the whole text, not one token.
  - required_software: output CANONICAL ids only (e.g. "blender", "unreal",
    "figma", "cinema4d"). Map both English and Korean names to the canonical id.
    Omit anything that is not a concrete tool.
  - remote_flag: true if the posting offers remote or hybrid work (재택 /
    재택근무 / 원격 / 원격근무 / 하이브리드 / remote); false if it explicitly
    requires full-time office presence; null if not stated either way.
  - site_intensity: 0-10 estimate of physical site-work demand. 0 = pure desk
    work; ~3 = occasional light visits (실측, client 미팅); 7+ = regular 현장 /
    시공 / 설치 / 감리 / 출장 / 매장 presence; 10 = constant physical site
    labour. Judge from duties described, not just keywords. Null if no signal.
  - why_it_fits: 1-2 neutral sentences on fit for a spatial/3D career switcher.
  - skills_to_learn: tools/skills the posting demands (canonical where possible).
  - extraction_confidence: 0-1. Lower it when the posting is thin, ambiguous, or
    you had to guess the career mapping.
